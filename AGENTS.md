# Thuis

For an installation request, read README.md and INSTALL.md and complete the local install and verification. Keep passwords in the browser's first-run form, never in chat. Preserve existing checkouts and private data.

For code work, run the relevant Python HTTP/SQLite tests and editor tests. Rebuild editor assets after editor changes. Data lives outside this repository (default ~/.thuis). Never commit databases, uploads, credentials, config.json, real screenshots, or machine-specific launchers. Keep the public app empty on first run and its optional integrations disabled until configured by its owner.
